# MacBook Pro 売却前バックアップ ＆ Mac Studio への全移行 手順

目的
1. MacBook Pro の全データ（書類・写真・アプリ・設定・ローカルのキーチェーン）を、バッファロー製USB HDDに **暗号化Time Machine** で保存する
2. そのバックアップ（または旧Macから直接）を使って、**Mac Studio で旧Macと同じ環境をそのまま編集・操作できる** ようにする

> スクリプトはすべて「読み取り」か「Time Machineの開始」だけです。ディスクの初期化・削除・パーティション変更、Mac本体のサインアウト・消去は **一切行いません**。
> 結果レポートはデスクトップに `backup_report_*.txt` として保存されます。パスワードや鍵の中身は表示・記録しません。

---

## 手順0　準備（1分）
1. このフォルダ（`mac-backup`）を MacBook Pro にダウンロード（例：デスクトップ）
2. **システム設定 > プライバシーとセキュリティ > フルディスクアクセス** で「ターミナル」をオン（検証で全ファイルを見るため）
3. 電源アダプタを接続し、バッファローHDDをUSB接続

## 手順1　読み取り専用の調査（自動・5〜15分）
```bash
cd ~/Desktop/mac-backup
bash 01_survey.sh
```
レポートで次を確認します（共有する場合、児童名などが含まれる行は伏せてください）。
- 外付け物理ディスクが **1台だけ** で、BUFFALO と表示されるか → 複数ある場合は対象を特定するまで先に進まない
- HDDの **容量** が内蔵ディスク使用量の **1.5倍以上** あるか
- HDDの **フォーマット** と **既存データ**

## 手順2　バックアップ先の設定（本人操作・ここだけ判断が必要）
HDDのフォーマットによって分岐します。**消去を伴う操作は、下の表で対象と影響を確認し、ご自身で承認してから** 行ってください。

| HDDの状態（手順1の File System Personality） | 対応 | 既存データへの影響 |
|---|---|---|
| 空、または消えてよいデータのみ | Time Machine設定でそのまま選択（消去の確認が出る） | **HDD全体が消去される** |
| APFS で既存データあり・空きが十分 | 既存コンテナに Time Machine 用ボリュームを追加（ディスクユーティリティ「＋」→ ボリューム追加） | 既存ボリュームは残る（構成変更なので、念のため事前に重要データを別所へ複製推奨） |
| exFAT / NTFS / HFS+ で既存データあり | 既存データを別の場所に退避 → 退避を確認してから消去 | **退避しないと失われる** |

設定方法：**システム設定 > 一般 > Time Machine > バックアップディスクを追加** → バッファローのボリュームを選択 → **「バックアップを暗号化」をオン** → パスワード設定

### 暗号化パスワードの扱い（重要）
- パスワードは **ご自身で** 画面に入力してください。チャットやメモアプリの平文、スクリプトには書かないでください。
- 次の **2か所** に保管すると安全です：①パスワード管理アプリ（Appleの「パスワード」アプリ／1Passwordなど、新しいMacでも開けるもの）、②紙に書いて自宅の安全な場所へ
- このパスワードを忘れると **バックアップは復元できません**（Appleでも解除不可）
- 「ヒント」にパスワードそのものを書かないでください

## 手順3　バックアップ実行（自動・数時間）
```bash
bash 02_start_backup.sh
```
進捗を1分ごとに表示し、終了後に直近のエラーを抽出します。初回はHDD・USB速度により数時間かかります。スリープ防止のため蓋を開けたまま、電源接続で。

## 手順4　Time Machineだけでは残らないもの
| 対象 | なぜ残らないか | 保存方法 |
|---|---|---|
| iCloud Driveの「iCloudのみ」ファイル（調査の dataless 件数） | 実体がMacに無い | Finderで iCloud Drive（または該当フォルダ）を右クリック →「今すぐダウンロード」→ 再度手順3。空き容量が足りなければ、iCloudに残っているので Apple ID を維持すれば Mac Studio でも見られる |
| 写真（「Macのストレージを最適化」オン時の原本） | 原本はiCloudのみ | 写真 > 設定 > iCloud >「オリジナルをこのMacにダウンロード」→ 完了後に再バックアップ。容量不足ならiCloud側に原本が残る |
| iCloudキーチェーン／Appleの「パスワード」 | iCloudに同期 | 同じApple IDで Mac Studio にサインインすれば戻る（TMのローカルキーチェーンにも入る） |
| ローカル（login）キーチェーン | TMに入るが **旧Macのログインパスワード** で暗号化 | 旧Macのログインパスワードを控えておく（移行後のロック解除に必要） |
| Chromeのパスワード | Chrome独自DB。Macの鍵で暗号化され、別Macでは読めない場合がある | Chromeで Googleアカウントにログイン → 同期で「パスワード」をオン → passwords.google.com で件数確認。**CSV書き出しはしない** |
| 1Password/Bitwarden等 | クラウド保管庫ならサーバーに有り | マスターパスワード・Emergency Kit（秘密鍵）を確認。ローカル保管庫（.kdbx 等）は手順1で件数確認、TMに含まれるか手順5で確認 |
| ゴミ箱・キャッシュ・除外設定したフォルダ | TMの仕様で除外 | 必要なら除外を解除、またはゴミ箱から戻す |
| アプリのライセンス認証（Adobe/Office等） | 端末単位 | Mac Studioで再サインイン（旧Macの認証解除は売却直前に別途） |
| 2段階認証アプリ | 主にスマホ側 | 本作業の対象外。スマホ側を確認 |

## 手順5　検証（自動・10〜30分）
```bash
bash 03_verify.sh
```
- 最新バックアップの日時・一覧
- 主要フォルダの **ファイル数比較**（Mac側／バックアップ／iCloudのみ）
- 書類・デスクトップ・写真から **20ファイルを無作為に内容比較**（cmp）
- 除外設定、直近7日のエラー、暗号化の有無

**「警告 0件」かつ抜き取り不一致 0件** を確認してから次へ。警告があれば内容をお知らせください（ファイル名に個人名が含まれる場合は伏せて）。

## 手順6　Mac Studio で全てを使えるようにする（移行アシスタント）
おすすめ順：
1. **旧Macから直接移行（最も確実）**：両方のMacを同じWi-Fi、できれば Thunderbolt/USB-C ケーブルで直結 → Mac Studio の初期設定中に「Mac、Time Machineバックアップ、または起動ディスクから」を選択 → MacBook Pro 側で「移行アシスタント」→「別のMacへ」
2. **Time Machineバックアップから移行**：バッファローHDDを Mac Studio に接続 → 移行アシスタント → Time Machineバックアップを選択 → **暗号化パスワードを入力**
   - 移行対象：ユーザ（書類・写真）、アプリ、コンピュータとネットワークの設定、その他のファイル を **すべてチェック**

移行後、Mac Studio で：
```bash
bash 04_after_migration_check.sh
```
- ファイル数（手順5の数値と比較）、アプリ数、Intel専用アプリ（Rosetta要否）、キーチェーンを確認
- Apple ID / iCloud・Chrome・パスワード管理アプリに **サインインし直し**、同期件数を確認
- Mac Studio で問題なく使えることを数日確認してから、旧MacBookの初期化に進む（初期化・サインアウトは本手順の対象外）

|---|---|---|---|
| `01_survey.sh` | MacBook Pro | 機種・OS・ディスク・HDD・TM設定・iCloudのみ・パスワード保管場所を調査 | なし |
